# Исправление логики Market, карточек и игрового поля

## 1. Проверить логику Market

Обнаружена ошибка.

### Сценарий

1. Игрок купил карточку **Gold (Small Deal)**.
2. Позже игрок попадает на клетку **Market**.
3. Появляется уведомление, что есть покупатель на золото.
4. После этого карточка сделки НЕ открывается.
5. Игрок не может завершить продажу и нет возможности продать. 

### Ожидаемое поведение

Если у игрока есть актив, который хочет купить Market:

- автоматически открыть карточку продажи;
- показать полную информацию о сделке;
- вывести кнопки:
    - Продать
    - Отказаться

После продажи:

- удалить актив из инвентаря игрока;
- начислить деньги;
- изменить Cash Flow (если требуется);
- обновить баланс;
- закрыть сделку.

Если актива нет:

- ничего не открывать;
- показать уведомление:

> У вас нет подходящего актива для продажи.

---

Карточки бизнеса.
