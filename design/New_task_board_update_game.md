## Задача 6. Качество кода

Во время доработок:

- не ломай существующую функциональность;
- не переписывай рабочие части без необходимости;
- удаляй дублирование кода;
- используй переиспользуемые компоненты;
- соблюдай строгую типизацию TypeScript;
- сохраняй текущую архитектуру проекта.

Если видишь возможность улучшить решение — сначала объясни, почему это лучше, а затем реализуй.

Главная цель — сделать MVP максимально качественным, красивым, стабильным и готовым для первых пользователей.
