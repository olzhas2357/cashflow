Мы продолжаем разработку CashYou — онлайн-версии настольной игры Cashflow.

На данный момент уже реализовано:

- Регистрация пользователей.
- Авторизация.
- Создание комнаты (Host).
- Подключение игроков.
- Базовая многопользовательская игра.

Теперь необходимо улучшить проек

Перед началом реализации:

1. Проанализируй.
2. план улучшений.
---

## Задача 1. Улучшение главной страницы

Сделай главную страницу более современной, понятной и привлекательной.

Необходимо добавить:

• красивый Hero-блок;

• описание проекта CashYou;

• блок «Играй с друзьями онлайн»;

• блок «Создай комнату за несколько секунд»;

• блок «Присоединяйся по коду комнаты»;

• информацию о поддержке нескольких языков;

• красивые кнопки:

- Играть сейчас
- Создать аккаунт
- Войти

Главная страница должна вызывать желание начать играть.

---

## Задача 2. Экран завершения игры

После окончания партии необходимо сделать полноценный экран завершения игры.

Показать:

- Победителя.
- Итоговое место каждого игрока.
- Финальный капитал.
- Общую стоимость активов.
- Пассивный доход.
- Итоговую статистику.

Добавить кнопки:

- Играть снова
- Вернуться на главную
- Посмотреть результаты игры

Экран должен выглядеть современно и красиво.

---

## Задача 3. Полная локализация приложения (ОЧЕНЬ ВАЖНО)

Необходимо полностью перевести приложение.

Поддерживаемые языки:

- Русский
- Английский
- Казахский

Перевести абсолютно весь текст приложения:

- меню;
- кнопки;
- формы;
- сообщения об ошибках;
- уведомления;
- модальные окна;
- подсказки;
- игровой интерфейс;
- карточки;
- профессии;
- финансовые термины;
- настройки;
- профиль;
- регистрацию;
- авторизацию;
- главную страницу;
- экран завершения игры.

Не должно остаться ни одной захардкоженной строки.

Использовать полноценную архитектуру i18n.

Создать отдельные файлы переводов:

- ru.json
- en.json
- kk.json

Структура переводов должна быть удобной для дальнейшего расширения.

## Задача 4. Улучшение карточки игрока

Во время игры необходимо сделать карточку игрока более информативной.

Отображать:

## Задача 6. Качество кода

Во время доработок:

- не ломай существующую функциональность;
- не переписывай рабочие части без необходимости;
- удаляй дублирование кода;
- используй переиспользуемые компоненты;
- соблюдай строгую типизацию TypeScript;
- сохраняй текущую архитектуру проекта.

Если видишь возможность улучшить решение — сначала объясни, почему это лучше, а затем реализуй.

Главная цель — сделать MVP максимально качественным, красивым, стабильным и готовым для первых пользователей.
