# Задача: новая главная страница CashFlow

## Исходник
Файл дизайна: `design/ghost-cursor.html` (HTML + CSS + JS).
Разбери его: отдельно эффект курсора, отдельно вёрстку.
НЕ вставляй как есть — портируй в React + TypeScript.

## Структура страницы (сверху вниз)
1. Хедер: логотип + переключатель языка KZ / RU / EN
2. Hero: название, одна строка описания, две кнопки:
   - «Создать игру» → создаёт комнату сразу, без регистрации
   - «Войти по коду» → поле на 6 символов
   - под ними мелким: «Без регистрации · 2–6 игроков · 20 минут»
3. Три блока «как играть»: создай → отправь ссылку друзьям → играйте
4. Футер: GitHub, контакт

## Обязательно
- Mobile-first, проверить на 360px. На телефоне кнопки — на весь экран.
- От открытия сайта до входа в комнату — максимум 3 экрана.
- Эффект курсора: только десктоп (`pointer: fine`),
  выключить при `prefers-reduced-motion`,
  обязательно `cancelAnimationFrame` в cleanup useEffect.
- Никаких текстов хардкодом в JSX — только `t('key')` (react-i18next).
- OG-теги + og:image 1200x630 — ссылка должна красиво
  выглядеть при отправке в WhatsApp и Telegram.
- Lighthouse Performance ≥ 90 на мобильном.

## Не делать
- Не трогать игровое поле и WebSocket-логику
- Не добавлять экран регистрации перед игрой
- Не ставить тяжёлые анимации на мобильном

## Проверка
Открыть на телефоне и на десктопе → нажать «Создать игру» →
получить код и ссылку → открыть ссылку во второй вкладке → войти вторым игроком.
